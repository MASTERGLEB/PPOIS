# ППОИС_1 --- операции над 3D-векторами

Консольное приложение на C++, демонстрирующее работу с классом `Vector`
и перегрузку операторов для основных операций над векторами в трёхмерном
пространстве.

## Возможности

Программа позволяет:

-   вводить два вектора по координатам начала и конца;
-   выводить текущие значения векторов;
-   вычислять длину каждого вектора;
-   складывать и вычитать векторы;
-   вычислять векторное произведение;
-   умножать векторы на число;
-   делить векторы на число;
-   выполнять покомпонентное деление одного вектора на другой;
-   вычислять косинус угла между векторами;
-   сравнивать векторы по их длине.

### Представление вектора

Вектор задаётся двумя точками:

``` text
(x1, y1, z1) -> (x2, y2, z2)
```

Компоненты вычисляются как:

``` text
dx = x2 - x1
dy = y2 - y1
dz = z2 - z1
```

Длина:

``` text
|v| = sqrt(dx² + dy² + dz²)
```

## Запуск

Проект предназначен для Visual Studio и содержит `.sln` и `.vcxproj`.

Требования проекта:

-   Windows;
-   Visual Studio с поддержкой C++;
-   Platform Toolset: `v143`;
-   Windows SDK 10.0 или совместимый.

Откройте `ппоис_1.sln`, соберите решение и запустите приложение.

В архиве также присутствует готовая версия:

``` text
x64/Debug/ппоис_1.exe
```

## Работа с программой

После запуска отображается меню:

``` text
1. Ввести вектор 1
2. Ввести вектор 2
3. Показать векторы
4. Длина вектора 1
5. Длина вектора 2
6. Сложение
7. Вычитание
8. Векторное произведение
9. Умножение на число
10. Деление на число
11. Деление векторов
12. Косинус угла
13. Сравнение длин
0. Выход
```

Для ввода вектора используются шесть чисел:

``` text
x1 y1 z1 x2 y2 z2
```

Например:

``` text
1 2 3 4 6 3
```

задаёт вектор из точки `(1, 2, 3)` в точку `(4, 6, 3)`.

## Реализация

Основные файлы:

-   `main.cpp` --- консольное меню и обработка пользовательского ввода;
-   `vector.h` --- объявление класса `Vector`;
-   `Vector.cpp` --- реализация класса и перегруженных операторов.

### Перегруженные операторы

  Оператор               Назначение
  ---------------------- --------------------------------------------
  `+`, `+=`              сложение по координатам точек
  `-`, `-=`              вычитание по координатам точек
  `*` с `Vector`         векторное произведение
  `*` с `double`         умножение на число
  `/` с `Vector`         покомпонентное деление разностей координат
  `/` с `double`         деление на число
  `^`                    косинус угла между векторами
  `==`, `!=`             сравнение компонент векторов
  `<`, `<=`, `>`, `>=`   сравнение по длине
  `<<`                   вывод вектора
  `>>`                   ввод вектора

## Обработка ошибок

При делении программа проверяет делитель. При делении на ноль
выбрасывается `std::runtime_error`, который перехватывается в `main()` и
выводится пользователю.

Для покомпонентного деления двух векторов проверяется каждая компонента
второго вектора: если хотя бы одна компонента равна нулю, операция
завершается ошибкой.
