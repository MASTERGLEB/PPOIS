# ППОИС_1_1 --- интерпретатор системы подстановочных правил

Консольное приложение на C++, реализующее простую машину подстановок над
строкой. Программа загружает начальную ленту и набор правил из
текстового файла, после чего последовательно применяет правила к строке.

## Идея работы

Программа использует две основные сущности:

-   **лента (`Tape`)** --- строка, над которой выполняются замены;
-   **программа (`Program`)** --- последовательность правил вида
    `левая_часть->правая_часть`.

Правила проверяются сверху вниз. На каждом шаге программа ищет первое
правило, левая часть которого встречается в текущей строке, и заменяет
**первое найденное вхождение**.

Правило может быть терминальным. Для этого перед правой частью ставится
точка:

``` text
левая_часть->.правая_часть
```

После выполнения терминального правила вычисление останавливается.

## Формат входного файла

Первая строка содержит исходную ленту.

Следующие строки содержат правила:

``` text
левая_часть->правая_часть
```

Терминальное правило:

``` text
левая_часть->.правая_часть
```

Пример из проекта (`input.txt`):

``` text
pvios ib beast 
pvios->ne
beast->.abc
```

Преобразование:

``` text
pvios ib beast
ne ib beast
ne ib abc
```

На втором правиле стоит `.`, поэтому после этой замены выполнение
прекращается.

## Запуск

Проект предназначен для Visual Studio.

Требования:

-   Windows;
-   Visual Studio с поддержкой C++;
-   Platform Toolset: `v143`;
-   Windows SDK 10.0 или совместимый.

Откройте:

``` text
ППОИС_1_1.sln
```

Соберите решение и запустите приложение.

В архиве также находится готовый исполняемый файл:

``` text
x64/Debug/ППОИС_1_1.exe
```

### Запуск из командной строки

Общий формат:

``` text
ППОИС_1_1.exe <файл> [-log]
```

Например:

``` text
ППОИС_1_1.exe input.txt
```

Для вывода состояния ленты после каждого шага:

``` text
ППОИС_1_1.exe input.txt -log
```

Если файл не указан, программа выводит подсказку по использованию и
завершает работу.

## Алгоритм выполнения

1.  Создаётся объект `Machine`.
2.  Из указанного файла загружается исходная лента.
3.  Из оставшихся строк загружаются правила.
4.  На каждом шаге правила просматриваются в порядке их появления.
5.  Для первого подходящего правила выполняется замена первого
    вхождения.
6.  Если правило обычное, выполнение продолжается.
7.  Если правило терминальное, выполнение завершается.
8.  Если ни одно правило не подходит, выполнение также завершается.
9.  В конце выводится итоговое состояние ленты.

При использовании `-log` состояние ленты дополнительно выводится после
каждого шага.

### Назначение классов

**`Tape`**\
Хранит строку и предоставляет `replaceFirst(from, to)`, заменяющую
первое вхождение `from` на `to`.

**`Rule`**\
Хранит левую часть, правую часть и признак терминальности правила.

**`Program`**\
Хранит список `Rule`, загружает правила и выполняет один или несколько
шагов преобразования.

**`Machine`**\
Объединяет ленту и программу, загружает их из файла и запускает
вычисление.

**`main.cpp`**\
Обрабатывает аргументы командной строки, запускает машину и выводит
результат.

## Важные особенности

-   Порядок правил имеет значение: используется первое подходящее
    правило.
-   За один шаг заменяется только первое найденное вхождение.
-   Пустые строки при загрузке программы пропускаются.
-   Строки без `->` игнорируются при загрузке правил.
-   Пустая левая часть правила не выполняет замену.
-   Терминальность определяется символом `.` непосредственно после `->`.
-   Если ни одно правило не применимо, программа останавливается.
-   При невозможности открыть входной файл программа сообщает об ошибке
    и завершается с кодом `1`.

## Дополнительный пример

Входной файл:

``` text
abcabc
abc->X
X->.done
```

Ход выполнения:

``` text
abcabc
Xabc
done
```

Сначала заменяется первое `abc` на `X`. Затем применяется второе
правило, которое является терминальным, и программа останавливается.
